# Get More Ram (ខ្មែរ / Khmer Edition)

A Khmer-localized fork of [hugeBlack/GetMoreRam](https://github.com/hugeBlack/GetMoreRam) — 
a simple StosSign wrapper app that lets you enable "Increased Memory Limit" for your 
sideloaded apps without needing Xcode.

This fork forces the entire app into **Khmer (ខ្មែរ)**, making it accessible to Cambodian 
sideloading users who want a native-language experience.

## What's different from the original
- 🇰🇭 Fully translated UI, error messages, and alerts into Khmer
- App is forced to always launch in Khmer regardless of device system language
- Rebranded bundle identifier for independent distribution

## How to use
1. Sideload this app
2. Go to Settings, sign in with the Apple ID used to sign the app you want to enable "Increased Memory Limit" for
3. Go to "App IDs"
4. Tap Refresh
5. Tap the app you want to enable "Increased Memory Limit" for
6. Tap "Add Increased Memory Limit"
7. Reinstall the app from SideStore/AltStore
8. Check if you have "Increased Memory Limit"
